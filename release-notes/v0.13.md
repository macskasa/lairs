# Lairs Tracker v0.13

Released 20 November 2026

## New

- **The tracker follows your game progress.** Tools and rules now match the boxes and envelopes you've opened, set in **Settings → Game progress**.
  - **No spoilers:** nothing from a package you haven't opened is shown or hinted at. Missing tools are simply hidden.
  - **Coming soon:** packages the tracker doesn't support yet are marked on the progress track. Tapping one only says "Coming soon."
- **Loading a save from a player further along:** the app tells you which package that player had opened, and offers to set your progress to match before loading. You can also cancel.
- **Changing progress mid-game:** this works as long as it doesn't change what has already happened in the game. If it would, the app asks first and offers to start a new game instead.

## Changed

- **Trap moves** follow the rules for the packages you've opened.
  - **Deciding the move type:** when a move could be a normal step or backtrack, it counts as one. Only moves that need the trap count as trap teleports.
  - **Removing a trap:** this now affects only the teleports that came from it.
- **Save files** now record which moves were trap teleports.
- **Route marks:** the ⇢ mark and the dashed arcs now stand for backtracks and trap teleports.
- **Example map:** it shows only what's available from the first box.
- **Compass:** stepping with it uses exactly the same checks as tapping a square.

## Tested on

- **Galaxy S24 Ultra and Galaxy S22 Ultra:**
  - As an installed app, with gesture and button navigation.
  - In a Chrome tab.
  - In landscape.
- **iPhone 15 and iPhone SE.**
- **3:4 tablet** (768×1024), both ways.
- **16:9 screen** (1280×720), both ways.

A scripted run checked the movement and map rules at each supported progress step, as well as the load and progress prompts.
