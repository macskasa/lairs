# Lairs Tracker v0.23

Released 21 November 2026

## Changed

- **Hungarian: the lair is now "kazamata"** everywhere, instead of "odú". For example: Kazamata készítése, Kazamatakód, Új szóló kazamata.
  - **Make a lair's new-lair button** reads **Újat** in Hungarian, so it fits on phones.
- **About:** "Kids Table Board Gaming" in Settings → About is now a link to the publisher's website, in both languages.

## Tested on

- **Galaxy S24 Ultra and Galaxy S22 Ultra:**
  - As an installed app, with gesture and button navigation.
  - In a Chrome tab.
  - In landscape.
- **iPhone 15 and iPhone SE.**
- **3:4 tablet** (768×1024), both ways.
- **16:9 screen** (1280×720), both ways.

**What was checked:**
- **Layout in Hungarian and English:** every screen above, with nothing scrolling or cut off. That includes the Game tab buttons, Make a lair's buttons and the tool labels.
- **No English left:** the Hungarian tracker, Make a lair and Settings were checked for leftover English.
- **The About link:** it opens the publisher's site in a new tab, in both languages.
