# Lairs Tracker v0.14

Released 20 November 2026

## Changed

- **Backtracks follow the rulebook.**
  - **The way:** a backtrack now passes only through known, **empty** squares. Any feature that's still there stops it: an active trap, a monster, an unopened chest, the Start or the Exit. Filled-in (eliminated) features count as empty, as before.
  - **The destination:** you can now backtrack into any known square, even one with an active trap or monster.
  - **Unchanged:** walls still block a backtrack, and a trap teleport still counts only when a backtrack isn't possible.
  - **When a backtrack isn't possible,** the message says so: "No way from F1 to D4 through known, empty squares."
  - **Earlier moves:** backtracks are checked when you make them. Later changes to the map don't remove them.

## Tested on

- **Galaxy S24 Ultra and Galaxy S22 Ultra:**
  - As an installed app, with gesture and button navigation.
  - In a Chrome tab.
  - In landscape.
- **iPhone 15 and iPhone SE.**
- **3:4 tablet** (768×1024), both ways.
- **16:9 screen** (1280×720), both ways.

A scripted run checked backtracks past chests, monsters, traps, the Start and the Exit, both before and after they're filled in. It also re-checked the earlier movement and progress rules.
